# Murage 1.0.7

This update lets your bots read the projects and groups they belong to, adds a phone layout, ElevenLabs voices through Flux and a typed stop, and makes backups, routines and Linux starts run straight through.

## What's new

- Bots read where they belong: a bot can read the messages of its own projects and groups when you ask it to.
- A phone layout: on a narrow screen the chat header and the composer fold into compact menus, with Stop, Attach and the approval level one tap away.
- ElevenLabs voices through Flux: with Flux connected, calls and voice replies can use the ElevenLabs voices Flux offers.
- Type stop: write "stop" and the running turn ends, on every engine. A "stop" sent as a reply to a line stays an ordinary message.
- News from Murage: the first run asks once whether you want product news, and Settings > About keeps the choice.

## Improvements

- Back up now runs straight through on long histories, says which backup it is taking, and confirms it was saved and checked.
- At No limits, your own routines answer read-only commands on their follow-through turn without stopping for an approval card.
- Your own routines in a project room run at the level you set for the routine and its bot, and runs started from outside keep asking.
- On Linux, Murage uses the graphics card on Intel and AMD for smoother scrolling and video.
- On Linux and WSL, Murage relaunches cleanly after it was started from a terminal.
- Logging out or shutting down saves the chat in progress before Murage quits.
- Long tool runs that report progress keep going, and the working indicator stays until the turn really ends.
- A new bot is created in one step, so a bot that cannot be created leaves nothing half made.
- Murage opens steadily while another process is busy with its database.
- A message sent while memory is still checking a line waits for the check, then goes out with the right context.
- Tool errors from apps reach your bot as readable text, and engine versions show for every engine.
