Murage 1.0.12 is out for Mac, Windows and Linux, led by help on every screen and a start that clears deleted chats in the background.

## Help on every screen
- Press the ? key or the ? button and a help panel opens with tips and search, in every window.

## New
- **Find anything in Settings.** Type in the Settings search box and the matching cards appear. The command palette searches Settings too.
- **Update progress you can read.** Starting with the next update, a small box at the bottom left shows the status and percent while a download runs. Escape closes it.
- **Phone previews in Settings.** Settings has a Preview card under Phone and other devices with two switches, phone tools and share and ask. Both start off.

## Better
- Murage opens first and finishes clearing deleted chats in the background after it is up.
- If a start takes longer than usual, the recovery window says so and offers Retry startup.
- A long direct chat turn can stay quiet for up to 60 minutes before Murage stops it.
- A Full access routine keeps running when the computer's environment check is slow.
- Needs you counts a routine's waiting card once.
- A thread folder Murage makes shares the trust of the bot's workspace, so it raises no extra card.
- Memory keeps what is worth keeping: thin, placeholder and passing notes stay out.
- A changed bot picture shows straight away on desktop and phone, and every bot keeps its own face.
- Changing or removing a Flux key shows a restart notice in Models.
- A read-only backup folder gets its own plain message, a full disk message names both drives, and the recovery window shows progress.
- Murage starts a fresh server log at launch once the old one passes 50 MB, and keeps one old copy.
- Choosing the computer's time zone again takes effect without a restart on Windows.
- When an organization has turned off plan access for a Claude login, Murage says where to switch accounts: Settings, then Models, Advanced, Claude accounts.
- A Codex bot on Windows can explain a named-pipe refusal and offer to run the step on a Claude bot.
- Error text and logs mask more forms of a key.
- More of Murage follows your system's reduced motion setting.

## How to update
- Murage shows an update banner when 1.0.12 is ready. You can also choose Check for updates in Settings.
