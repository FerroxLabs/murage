# Murage 1.0.8

This update lets Full access and No limits run your everyday commands on Windows without stopping for approval, delivers every approval you give, and makes updates and new chats clearer.

## What's new

- Full access on Windows: Codex, Fuigo, Claude and Pi run ordinary commands in PowerShell and Git Bash at Full access and No limits, and keep asking before anything that wipes, reads secrets, pays or messages someone new.
- Apply to my open conversations: when you raise a bot's default level, Murage offers to bring its open chats up to it in one step and shows how many are still at Ask.

## Improvements

- When PowerShell starts slowly, your own commands at Full access and No limits still run, with the shell environment marked as unchecked.
- Approvals a helper bot asks for now reach you and carry its work on once you answer.
- The sidebar shows one update button, with the full check, download and restart steps.
- Fuigo starts reliably in Cloud homes.
- A turn that ends without a reply always says why.
- Memory learning names the reason when a summary cannot be used and tries again later.
- Logs are quieter and never carry message or command text.
