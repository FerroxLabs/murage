# Murage 1.0.24

Automatic is now the way new bots start, and Fuigo moves up to version 1.0.48.

## What's new

- New bots start on Automatic. In the desktop app, a short card above the message box explains it once, with a Learn more link, and the level chip beside the box switches between Automatic and Ask first.
- Fuigo updates to version 1.0.48.
- Memory: PENDING MEMGATE

## Improvements

- When a bot you own cannot reach its memory, it tells you and answers without it.
- The email event reader waits and retries while its database is busy.
