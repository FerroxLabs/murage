Murage 1.0.21 is out for Mac, Windows and Linux. Your Fuigo, Flux, Claude and Codex bots keep answering through memory changes, and an install that got stuck works again the first time you open it.

Send a photo to a bot in any chat, run two Fuigo bots at once on Windows, watch Sable stay Sable, and connect your own online MCP servers, like Metricool, right in your chats.

## Better

- **A stuck install works again.** The first time you open 1.0.21, Murage puts things right in the background and keeps your chats and settings. A tool that can't start is no longer mistaken for a memory refusal: it is set aside with a short note, and your bot carries on with everything else. Nothing to run, nothing to reinstall.
- **A bot working in a folder you picked may ask once to trust it.** You answer one time, and the bot gets on with the job.
- **Replies carry on when memory changes mid-reply.** A bot finishes its turn with the context it can still use, and Stop and Stop All hand back a clear answer every time.
- **Your bot keeps the memory that still applies.** When a notebook syncs again, passages with unchanged words stay in use, so replies stay grounded.
- **Memory catches up faster on a Mac.** Queued memory updates are worked through together in the background.
- **Owner replies show up whole.** A reply is never hidden from your chat, and your next message is never held back by a long, clean brief.
- **Send pictures in any chat.** Attach a screenshot or photo to Claude or Codex, with or without a project, and in team rooms each message carries only its own picture.
- **Run two Fuigo bots at once on Windows.** Starting a second bot leaves the first one working exactly as it was.
- **Sable stays Sable.** She keeps her identity, and so does every room member, even when a message goes out without saved memory.
- **Online MCP servers you add connect in your chats.** Add a server like Metricool once, and your bots can use it in any conversation.
- **A missed delivery shows as a card with Retry.** In the desktop app, a message that didn't land appears as a card, and Retry sends it again.
- **A bot's questions show as a card again.** Even when it is working with no limits, you see the question in your chat and answer it right there.
- **Phone requests stay yours.** Phone tools run only on requests you start as the owner.
- **A tidier Library.** The Library catalog is refreshed, with the smart-trader bot's review details current.
- **Argon and Carbon move to new rates on December 1.** Murage shows the new rates in the model picker from that day, tied to the named provider.

## How to update

Murage shows an update banner when 1.0.21 is ready, or choose Check for updates in Settings. If your install was stuck, update and open Murage once. It does the rest.
