# Private generation contract amendment

MAIN's 2026-11-11 users.create rulings 1 and 2 authorize the retirement of the native password completion contract. The reviewed request and action bind `private_generated_password_v1`, meaning 32 private generated bytes and final recipient password setup in HighLevel. This replaces `desktop_password` in FrozenRequest and ActionBinding.

HighLevelActions.beginDispatch again returns only intent and held request. Its completeDesktopPassword method and the optional password parameter of sendFrozen are removed. The dedicated client's sendHeldWithPrivatePassword creates the credential only after every dispatch admission and durable barrier. No server route or renderer/main IPC accepts a password for this operation.

Only these four exact public declarations are amended. `testing/userscreate-contract-amendment.json` lists each exact old and new declaration. Historical F0.1/F0.2 tests first reverse this amendment, then reverse the prior password amendment, and retain their original digest assertions. Unrelated signature or schema changes remain failures. The current complete snapshot is independently checked by frozen-snapshot.test.ts. Provider endpoint/version, provider schema, identity policies and shared grants are unchanged by this amendment.
