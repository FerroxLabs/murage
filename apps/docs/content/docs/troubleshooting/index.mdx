## Collect useful evidence

Before opening an issue, record:

- Murage version and operating system;
- selected engine and model;
- the exact visible error, not only “it failed”;
- whether the same AI app works when you open it yourself;
- whether restarting only the affected task changes the result.

Never post keys, passwords, the web address you were sent back to after signing in, or anything from a file that stores sign-ins.
