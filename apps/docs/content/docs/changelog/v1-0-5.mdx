Murage 1.0.5 is the hotfix for 1.0.4. Everything in [1.0.4](/docs/changelog/v1-0-4) is included.

## Bots in 1.0.5

- **Bots can now clean up files across folders in one command.** A delete that names folders in different places, such as `/tmp/a` and `~/b`, or `C:\a` and `D:\b` on Windows, gets its answer straight away, so Murage keeps responding while the bot works. It still asks or stops exactly as your access level sets.
- **Fuigo now starts on Windows from every install, including npm.** Install Fuigo with npm, from its own installer, or use the one that ships with Murage, and your bots on Fuigo answer from the first turn.
