## Lighter in the background in 0.1.62

- **Murage uses far less disk and CPU while it sits in the background.** This matters most when you have a long history. The Inbox and approvals badge now update only when something changes, and the work no longer spills to temporary files. An idle Murage writes almost nothing to disk now.

## Long conversations in 0.1.62

- **Long conversations keep going.** A conversation with a very long history no longer stops with a memory limit error. The bot keeps answering, and it recalls from the most recent part of the conversation.
