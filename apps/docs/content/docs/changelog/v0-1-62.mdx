## Lighter in the background in 0.1.62

- **Murage uses far less disk and CPU while it sits in the background.** This matters most when you have a long history. The Inbox and approvals badge now update only when something changes. An idle Murage writes almost nothing to disk now.

## Long conversations in 0.1.62

- **Long conversations keep going, well past where most agents stop.** Keep one conversation running for weeks, like a sales thread or a long project, and your bot keeps answering with its memory and everything recent you have worked on together. There is no need to start over.
- **Bots keep answering after many automated tasks, and a damaged handoff file no longer blocks startup.** A bot that has handed off a lot of work to its helpers no longer goes quiet, and Murage now starts normally even if one handoff file is damaged.
