## Chats in 1.0.6

- **All chats.** Every conversation sits in one searchable list, opened from a wider chat pop-up.

## Bots in 1.0.6

- **Bots know where they belong.** Each bot knows which projects and groups it is part of.
- **Your own scripts run at Full access.** A script on disk, like `bash build.sh`, runs straight through at Full access and No limits. Ask and Auto still check with you first.

## Engines in 1.0.6

- **Fuigo starts faster on Windows.** Fuigo starts steadily from every install shape.

## Memory and data in 1.0.6

- **Quicker upkeep on long histories.** Deleting conversations finishes faster, and Stop on a routine ends it cleanly.
- **More numbers masked.** Account and card numbers you paste are masked in more formats, IBANs included.
- **Backups run straight through.** Backups know every folder Murage keeps.

## Everyday use in 1.0.6

- **A smoother first run.** An app connects under the label you confirm.
- **Kept downloads, in plain words.** Files you keep from the browser are reported as kept.
- **Clearer library cards.** Each template's card says in plain words what it does for you.
