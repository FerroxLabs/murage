Murage 1.0.4 is the hotfix for 1.0.3. Everything in [1.0.3](/docs/changelog/v1-0-3) is included.

## Claude in 1.0.4

- **Claude now asks before phone, web search and site tools.** Tapping, typing or swiping on your phone, web search, and publishing a site each show an approval card first, as your access level sets.
- **Claude on Windows with Git Bash now starts its approval tools reliably.** When Git for Windows is installed, Claude's turns reach Murage's approval tools, so Always ask shows its card as it should.
