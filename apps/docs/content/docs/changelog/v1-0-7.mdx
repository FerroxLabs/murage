## Bots in 1.0.7

- **Bots read where they belong.** A bot can read the messages of its own projects and groups when you ask it to.
- **Type stop.** Write "stop" and the running turn ends, on every engine. A "stop" sent as a reply to a line stays an ordinary message.
- **Routines at No limits.** Your own routines answer read-only commands on their follow-through turn without stopping for an approval card.
- **Routines in project rooms.** Your own routines in a project room run at the level you set for the routine and its bot, and runs started from outside keep asking.
- **New bots in one step.** A bot that cannot be created leaves nothing half made.

## Voice in 1.0.7

- **ElevenLabs voices through Flux.** With Flux connected, calls and voice replies can use the ElevenLabs voices Flux offers.

## Engines in 1.0.7

- **Long tool runs keep going.** A tool that reports progress keeps running, and the working indicator stays until the turn really ends.
- **Readable tool errors.** Errors from apps reach your bot as readable text.
- **Engine versions for every engine.** Murage reads the version of each installed engine.

## Memory and data in 1.0.7

- **Back up now runs straight through.** Backups finish on long histories, say which backup they are taking, and confirm the copy was saved and checked.
- **Your chat is saved at shutdown.** Logging out or shutting down saves the chat in progress before Murage quits.
- **Checked context.** A message sent while memory is still checking a line waits for the check, then goes out with the right context.
- **Steady opening.** Murage opens steadily while another process is busy with its database.

## Everyday use in 1.0.7

- **A phone layout.** On a narrow screen the chat header and the composer fold into compact menus, with Stop, Attach and the approval level one tap away.
- **News from Murage.** The first run asks once whether you want product news, and Settings > About keeps the choice.
- **Smoother on Linux.** Murage uses the graphics card on Intel and AMD, and relaunches cleanly on Linux and WSL after a start from a terminal.
