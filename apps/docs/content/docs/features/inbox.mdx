## Opening the Inbox

Press **Needs you** at the top of the sidebar. Its badge counts what is waiting on you. The tray menu's See all in Inbox opens the same place. The Inbox is in the desktop app.

The Inbox has views across the top: Needs you, Approvals, Decisions, Connections, Routines, Results and All. The first four show how many items they hold. Use Refresh to check again, and the search box ("Search results or bots") to find an item.

## Answering approvals in the Inbox

An approval in the Inbox can be answered right there with Allow once, Allow for this task or Deny. Open the request to see exactly what the bot would run. Questions a bot asked you are answered inline, the same way as in the conversation.

## Clear, Dismiss and Mark read

Each item has buttons for what it needs:

- **Open request**, **Open file** or **Open report** takes you to it.
- **Mark read** or **Mark unread**.
- **Clear** removes a failure, missed request or report that owes nothing. A cleared item comes back only if it happens again. **Clear all** clears every item that needs nothing from you.
- **Dismiss** removes an old connection request. **Dismiss all** dismisses every one at once.

These take effect straight away, and the list holds still while it refreshes.

## Snoozing an Inbox item

Snooze 1 hour hides an item until later; it then shows "Snoozed until (time)". Tick Show snoozed items to see them, and use Return to Inbox to bring one back early. Snooze is not offered on the Needs you view, because those items are owed to you. Reading or snoozing an approval does not answer it.

## Engines to sign in to

When an engine is installed but nobody is signed in to it, the Inbox lists it under Engines to sign in to with the sign-in command to run in a terminal. The Copy button copies the command.

If you don't use that engine, press **I don't use (engine)** and confirm with Turn it off. Bots stop using it. You can turn it back on in **Settings → Engines**.

## Connections to restore and routines

Connections to restore lists connected apps that need signing in again. Routines shows one line per routine, not per run, with Open latest run or Open the run that failed.
