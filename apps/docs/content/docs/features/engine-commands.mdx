## Engine commands

Type **/** in the message box. The menu shows Murage's own commands first, then a group named after the bot's engine (Claude Code, Codex, Grok Build, Fuigo, OpenCode, or any other ACP engine under its own name) with the commands that engine offers, read live from the engine.

Picking an engine command sends it straight to the bot's engine. A command that needs more input is put in the message box for you to finish. Codex's /review and /compact work, and Codex skills appear there too. If the group says "Start a chat to load (engine) commands", send the bot a message first.

Commands never interrupt a turn that is already running.

## Murage's own commands

- **/learn**: teach a reusable workflow from this conversation.
- **/setup**: walk through setting up your bots, and pick up where you left off.
- **/goal** (in channels): keep a team working until the goal is complete.
