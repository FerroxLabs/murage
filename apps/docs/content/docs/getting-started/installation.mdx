## Download a released build

Choose your computer below. Each link always downloads the latest published build.

| Platform | Recommended package | Notes |
|---|---|---|
| macOS Apple silicon | [Download `.dmg`](https://github.com/FerroxLabs/murage-releases/releases/latest/download/Murage.dmg) | Signed and notarized. Drag to Applications. |
| macOS Intel | [Download `.dmg`](https://github.com/FerroxLabs/murage-releases/releases/latest/download/Murage-intel.dmg) | Signed and notarized. |
| Windows x64 | [Download installer](https://github.com/FerroxLabs/murage-releases/releases/latest/download/Murage-setup.exe) | Per-user installer; Windows signing is not yet available. |
| Ubuntu 24.04 x64 | [Download `.deb`](https://github.com/FerroxLabs/murage-releases/releases/latest/download/Murage-amd64.deb) · [AppImage](https://github.com/FerroxLabs/murage-releases/releases/latest/download/Murage.AppImage) | The `.deb` is recommended; the AppImage is portable. |

<Callout type="warn" title="Windows SmartScreen">
  The Windows installer is not code-signed yet. Windows may show “Unknown publisher.” Verify that you downloaded it from the official Murage releases repository before choosing **More info → Run anyway**.
</Callout>

## Install an AI app

Murage needs at least one supported AI app installed on this computer and signed in. Claude and Codex are the most common starting points.

1. Install the AI app from the company that makes it.
2. Open it once in a terminal and finish signing in.
3. Restart Murage.
4. Open the model picker. Engines that are ready appear as usual; the others say what is missing.

See [Agent engines](../providers/index.mdx) for the full list and for choosing an engine's location yourself.

## Build from source

For developers. Requirements: Node.js 24 or newer, pnpm 10.33.0, and at least one supported AI app you are signed in to (a CLI, or command-line app).

```bash
git clone https://github.com/FerroxLabs/murage.git
cd Murage
corepack enable
pnpm install --frozen-lockfile
```

Run the background service, the web screens and the desktop window in separate terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

## Where data lives

Murage stores its application data under `~/.murage`. Electron window and browser data use the normal per-platform application data directory.
