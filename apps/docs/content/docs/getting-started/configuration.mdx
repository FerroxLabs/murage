Most people set Murage up from the app. The desktop app checks what you enter before saving it (for some services, such as Box and voice, it also tests the key), and keeps keys in your computer's own secure storage.

## Engine discovery

Murage looks for your AI apps in the usual install places and in the same places your terminal looks. If an engine is installed somewhere unusual, open **Settings → Models & engines** and use **Choose location…** on that engine.

Choosing the location yourself helps when you:

- keep more than one version of an AI app;
- start the app through your own wrapper;
- installed it in a folder desktop apps cannot see; or
- open Murage from a Windows shortcut or a Linux app menu, which can see different settings from your terminal.

## Optional keys

| Key | What it turns on |
|---|---|
| Flux Router key | Models and connected apps |
| Box key | Linux computers that run online |
| ElevenLabs key | Spoken replies and voice mode |
| OpenCode key | Another way to use OpenCode, instead of your OpenCode sign-in |

Chatting with the AI apps on this computer works without any of these keys.

## Environment configuration

For developers who run Murage from source or without a window: you can set supported startup settings (environment variables, settings a program reads when it starts) before starting Murage's background service. In the normal desktop app, use Settings instead: it checks what you enter and keeps keys out of the window's own code.

### Per-instance Claude tool scope

For developers who run Murage from source or without a window: separate Claude engines can get different built-in tools in Murage's settings file (`~/.murage/config.json`, a text file in JSON format):

```json
{
  "instances": {
    "claude-browser": {
      "driver": "claudeAgent",
      "config": {
        "tools": ["Read", "WebFetch", "WebSearch"],
        "disallowedTools": ["Bash(git *)", "Edit", "Write"]
      }
    }
  }
}
```

`tools` picks which of Claude's built-in tools it gets: an empty list turns them all off, and leaving it out keeps Claude's usual set. `disallowedTools` lists Claude tool names, or name patterns, it may never use. These settings do not give or pre-approve connected tools (MCP servers, the add-on tools a bot can use); those still follow that engine's connected tools and Murage's approval cards.

<Callout type="warn" title="Keep keys and passwords out of messages">
  A message becomes part of the conversation and may be sent to your AI service. Add keys in Settings instead.
</Callout>
