B2 note (2026-10-06): Claude Code also calls a Datadog intake (http-intake.logs.us5.datadoghq.com). It is deliberately NOT allowed; turns set CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC, DISABLE_TELEMETRY and DISABLE_ERROR_REPORTING so the refusal never stalls a turn. Proven on a fresh home by tools/b2/e2e-egress.py (lane dir).

A2 (DNS forwarder): `murage-egress-proxy.py dns` answers a turn's DNS from this same file: an allowed name gets the fixed synthetic address 5.255.0.1, everything else NXDOMAIN, nothing is sent upstream. Review rule: no allowlist entry may ever be a public DoH/DoT resolver. Accepted residual: under `*.oaiusercontent.com` a turn picks a label (about 234 bytes) per allowed TLS connection, which the proxy resolves once (at most 120 connections/min per engine) and which reaches only oaiusercontent.com's authoritative DNS (Sean accepted, 2026-10-23).
