## Mandatory R1 reconciliation

The historical response implementation uses a savepoint, reserves attempts before validation and converts all writer failures to memory refusals. Replace it with C's exact-connection BEGIN IMMEDIATE owner through actual synchronous enqueue. Validation work is metered; reserve one attempt/actual bytes per unique affected generation only after validation. Attribution rolls back on pre-enqueue failure. Once the writer is entered, false/throw may mean accepted bytes: persist attribution/accounting, preserve native errors, never resend automatically. Commit failure seals the generation.

Historical tests requiring rollback after destination invocation are amended accordingly. Alias rollback witnesses now fail during attribution before enqueue and assert zero writer calls; separate native/thenable cases retain possible-release attribution. Exact source assertions use boolean checks to avoid dumping complete product source into failure logs.

A's learning validators join C's context without another BEGIN or nested join. Expensive preparation and awaits remain outside the owner. Stop ordering stays before writer acquisition and is rechecked under the boundary. Serializing a frame or checking before write cannot grant later release authority.

The engine writer joins C's supplied private context or owns that same primitive directly. Serializers check the final byte cost but cannot charge or grant a later release.
