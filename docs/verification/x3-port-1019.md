- A new incarnation is seeded only by the folder actually handed to its driver spawn. No record, invalid attribution, failed publication or retired identity means unknown. The project folder never supplies an attached-shell guess.
- Claude's enforced wrapper supplies per-call cwd proof; Codex's actual permission cwd supplies per-call placement; Fuigo's versioned contract is gated and unverified engines stay on the record. Named driver proof cannot be inferred from the tool label alone.
- Preparation adds candidates before execution. Unknown remains until an attributed exit-zero completion proves an absolute builtin directory chain. A semicolon, pipeline, OR, negation, group, unresolved effect or unverified builtin cannot clear it. Only Codex currently reports an attributable exit code; production calls without builtin proof do not propose an install. A completion overlapping another request cannot clear unknown. Committed candidate unions are conservative: they retain old known alternatives rather than discard a possibly live place.
- A 33rd place sets capped/unknown. The first subsequent relative glob is K; EVERY later relative glob remains U/P5 until proof. Anchored words use their anchor. The one-K-then-unchecked r5 rule is superseded by the amendment/l4.
- POSIX words obey the leading-dot rule. Engines with an unproven option snapshot are conservatively dot-enabled; PowerShell and engine proofs follow their recorded dot state. Quoted POSIX patterns and language payload strings are not local shell expansions. Options are listed whole. Local shell payload dispatch is a closed set.
- Directory witnesses exempt only bare enumerators. Every downstream stage must be a permitted stdin-only filter. Descriptor duplication uses its destination at that point in redirect order: stderr redirected to a file is not the screen.
- Enumeration reads names, not contents. ENOENT/ENOTDIR removes only that branch. Other errors preserve an immutable frontier and apply threshold-1. Limits remain 50 ms per command (25 ms cd), eight shared admissions, 128 glob words, 32 places, 256 queued/visited directories, 2,000 entries and 65,536 matching steps.
- Every expansion carries typed literal/real witness paths independently of its first reason. NOLIM consumes those paths as literal filesystem names, without decoding them again as shell text, even when unreadable/credential evidence won first. Ordinary W/C/U/K findings run for owner No limits; the retained hook/relay row still has N2 metadata and remains excluded by existing card policy. Other origins and protected modes retain their findings.
- Bot PATH keeps today's order and appends existing fallback directories. No new bashrc sourcing. MCP KEEP is mcp:<per-launch nonce>:<names>; mismatches keep nothing.
