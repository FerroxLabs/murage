## Product fixes

- Retain an unknown path suffix instead of collapsing `~/"$X"` into a known
  home-root delete. Known empty/root assignments still produce wipe cards.
- Normalize a write destination before classifying it as a raw device;
  `/x/../dev/../w/y` reaches `/w/y` and is not disk erasure.
- Inspect literal sed `w`/`W` outputs and less `+!` executable shell text.
  Input filenames, search expressions, and printed command text remain data.
- Preserve `classification: "deny"` on No limits wipe verdicts. When the legacy
  reader recovers a catastrophe behind an earlier protected-path finding, the
  catastrophe owns the returned rule rather than the non-wipe path finding.
